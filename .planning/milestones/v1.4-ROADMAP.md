## Milestone Goal

Establish consistent visual language across all screens — resource and building icons with canonical colors, unified building detail sheets with dynamic per-building content, battle UI improvements, and removal of redundant title text from city screens.

---

## Phases

### Phase 25: Visual Constants
**Goal:** Every resource and building type has a canonical icon and color, used consistently in every screen that displays them.
**Requirements:** ICON-01, ICON-02, ICON-03
**Completed:** 2026-03-19

**Plans:**
- [x] 25-01-PLAN.md — Define visual constants, ResourceBadge widget, and replace all ad-hoc icon/color usage

**Accomplishments:**
- Created `visual_constants.dart` with canonical `Map<ResourceType, Color/IconData/String>` and `Map<BuildingType, Color/IconData>` maps
- Created `ResourceBadge` widget — CircleAvatar+letter for production resources, `Icons.wine_bar` for wine
- Eliminated 5 duplicate resource switch methods and 3 binary building icon conditionals across 6 consumer files
- 25 tests passing (18 constants + 7 widget)

---

### Phase 26: Building Detail Sheet
**Goal:** Tapping any building opens a large, scrollable bottom sheet with building-specific information and actions.
**Requirements:** BLDG-01, BLDG-02, BLDG-03
**Completed:** 2026-03-20

**Plans:**
- [x] 26-01-PLAN.md — Shared bottom sheet scaffold (header, stats, actions layout) + simple building stats + BuildingCell wiring
- [x] 26-02-PLAN.md — Dynamic content per building type (tavern, warehouse, production, barracks, shipyard) + downgrade backend + cleanup

**Accomplishments:**
- `showBuildingDetailSheet()` — DraggableScrollableSheet entry point wired to all 14 BuildingType values
- `BuildingSheetHeader`, `BuildingSheetSection`, `BuildingSheetUpgradeActions` shared scaffold widgets
- 5 complex stats widgets: TavernStats (wine slider), WarehouseStats (fill bars), ProductionBuildingStats (breakdown), BarracksStats (8 unit types + roster), ShipyardStats (5 naval types + roster)
- `downgrade-building` Edge Function — instant 50% refund, decrements level
- Deprecated cleanup: deleted `barracks_screen.dart`, `shipyard_screen.dart`, `building_upgrade_card.dart`, `/barracks` + `/shipyard` routes, `_ProductionBreakdownSheet`

**Requirements:** BTUI-01, BTUI-02
**Completed:** 2026-03-21

**Plans:**
- [x] 27-01-PLAN.md — Add cargoCapacityPerShip constant, _CargoCapacityRow widget in dispatch screen, Wave 0 test stubs
