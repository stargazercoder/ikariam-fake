## Critical Issues

### BUG-01: dispatch-units undefined constant (Severity 1)

**File:** `supabase/functions/dispatch-units/index.ts` line 32
**Impact:** MIL-05, CMBT-01

`calcTravelMinutes()` references `BASE_MINUTES_PER_GRID_UNIT` which is never declared. `BASE_SECONDS_PER_GRID_UNIT = 10` is declared but unused in the formula. The default parameter evaluates to `undefined`, causing `arrive_at` to become `NaN`. Dispatched units never arrive, breaking the Military → Combat E2E flow.

**Fix:** Declare `const BASE_MINUTES_PER_GRID_UNIT = BASE_SECONDS_PER_GRID_UNIT / 60;` before the function.

### Missing Phase 2 VERIFICATION.md (Severity 2)

Phase 2 (Core Economy) has no VERIFICATION.md file. All 9 requirements (RSRC-01 thru RSRC-04, BLDG-01 thru BLDG-05) are marked "partial" because they lack formal phase-level verification. Integration check confirms all wiring is sound.
