  <action>
    **resources_repository.dart:**
    - Class `ResourcesRepository` with const constructor
    - Method `Stream<List<CityResource>> watchCityResources(String cityId)` that returns `supabaseClient.from('city_resources').stream(primaryKey: ['id']).eq('city_id', cityId).order('resource_type').map((rows) => rows.map((r) => CityResource.fromJson(r)).toList())`
    - Provider: `final resourcesRepositoryProvider = Provider<ResourcesRepository>((ref) => const ResourcesRepository());`

    **buildings_repository.dart:**
    - Class `BuildingsRepository` with const constructor
    - Method `Stream<List<CityBuilding>> watchCityBuildings(String cityId)` — same pattern as resources, using `.stream(primaryKey: ['id']).eq('city_id', cityId).order('building_type')` mapped to CityBuilding.fromJson
    - Method `Future<Map<String, dynamic>> upgradeBuilding({required String cityId, required String buildingType})` — calls `supabaseClient.functions.invoke('upgrade-building', body: {'city_id': cityId, 'building_type': buildingType})`. On non-200 status, parse the error JSON and throw `BuildingUpgradeException(errorMessage)`. On 200, return the response data (includes finish_at, duration_minutes, target_level).
    - Class `BuildingUpgradeException implements Exception` with `final String message` and toString override
    - Provider: `final buildingsRepositoryProvider = Provider<BuildingsRepository>((ref) => const BuildingsRepository());`

    **resources_provider.dart:**
    - `final resourcesStreamProvider = StreamProvider.autoDispose.family<List<CityResource>, String>((ref, cityId) { ... })` — uses ref.read(resourcesRepositoryProvider).watchCityResources(cityId)
    - The stream is stored as a local variable before returning, to prevent subscription cancellation on rebuild (per research Pattern 5)

    **buildings_provider.dart:**
    - `final buildingsStreamProvider = StreamProvider.autoDispose.family<List<CityBuilding>, String>((ref, cityId) { ... })` — uses ref.read(buildingsRepositoryProvider).watchCityBuildings(cityId)

    **construction_provider.dart:**
    - `final constructionQueueProvider = StreamProvider.autoDispose.family<ConstructionQueueEntry?, String>((ref, cityId) { ... })` — streams construction_queue table filtered by city_id, maps to ConstructionQueueEntry.fromJson or null if empty
    - Use `supabaseClient.from('construction_queue').stream(primaryKey: ['id']).eq('city_id', cityId).map((rows) => rows.isEmpty ? null : ConstructionQueueEntry.fromJson(rows.first))`

    Follow the existing provider pattern: manual providers (no @riverpod code-gen) per project decision.
