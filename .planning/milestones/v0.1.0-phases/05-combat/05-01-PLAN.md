**20260312000004_battle_functions.sql:**
Create `resolve_battles()` as SECURITY DEFINER, search_path = ''. Must handle:

1. Unit stats as CONSTANT jsonb inside the function body (NOT a DB table):
   - v_unit_attack: {"hoplite":10,"phalanx":15,"archer":20,"cavalry":30,"catapult":40,"mortar":50,"medic":0,"cook":0,"cargo_ship":5,"ram_ship":25,"catapult_ship":35,"mortar_ship":45,"diving_boat":15}
   - v_unit_defense: {"hoplite":20,"phalanx":30,"archer":15,"cavalry":20,"catapult":10,"mortar":10,"medic":5,"cook":5,"cargo_ship":10,"ram_ship":20,"catapult_ship":15,"mortar_ship":15,"diving_boat":25}
   - v_naval_types: ARRAY['cargo_ship','ram_ship','catapult_ship','mortar_ship','diving_boat']

2. FOR b IN SELECT ... FROM public.battles WHERE next_turn_at <= NOW() AND status = 'active' FOR UPDATE SKIP LOCKED:

3. **Naval Phase:**
   - Sum attacker naval attack/defense from attacker_units where type IN v_naval_types
   - Sum defender naval attack/defense from defender_units where type IN v_naval_types
   - If both sides have zero naval units: naval_outcome = 'skipped', skip to land phase
   - If attacker has zero naval but defender has naval: naval_outcome = 'skipped' (no naval conflict — attacker land units still fight per Claude's discretion)
   - If attacker has naval but defender has zero naval: naval_outcome = 'attacker_won' with zero casualties
   - Otherwise compute casualties:
     - att_naval_loss_ratio = def_naval_total_attack / GREATEST(att_naval_total_defense, 1)
     - def_naval_loss_ratio = att_naval_total_attack / GREATEST(def_naval_total_defense, 1)
     - For each naval unit type: casualties = LEAST(floor(quantity * loss_ratio), quantity)
     - Update attacker_units and defender_units JSONB (subtract casualties, remove zero entries)
     - Record casualties JSONB
   - After naval phase: if attacker has zero surviving naval units AND had naval units before this turn → naval gate-keeper triggers: battle ends, defender wins. Set land_outcome = 'blocked'.
   - Determine naval_outcome from surviving units

4. **Land Phase** (only if naval gate-keeper NOT triggered):
   - Get Town Wall level: SELECT COALESCE((SELECT level FROM public.city_buildings WHERE city_id = b.defender_city_id AND building_type = 'town_wall'), 0) INTO v_wall_level
   - v_wall_bonus = 1.0 + 0.05 * v_wall_level
   - Sum attacker land attack/defense (non-naval unit types)
   - Sum defender land attack/defense (non-naval), multiply defender defense by v_wall_bonus
   - Compute casualties same formula as naval
   - Update attacker_units and defender_units JSONB
   - Record casualties

5. **End-of-turn:**
   - Check attacker total units (sum all values in attacker_units). If zero → defender_won.
   - Check defender total units. If zero → attacker_won.
   - INSERT INTO battle_turns with all phase results
   - If battle still active: UPDATE battles SET turn_number = turn_number + 1, next_turn_at = next_turn_at + INTERVAL '5 minutes', attacker_units = v_new_att_units, defender_units = v_new_def_units, updated_at = NOW()
   - If attacker_won: UPDATE battles SET status = 'attacker_won', updated_at = NOW(). Then update defender's city_units: DELETE FROM city_units WHERE city_id = b.defender_city_id AND unit_type = ANY(array of types that were in the battle snapshot). Then create return movement: INSERT INTO unit_movements (owner_id, origin_city_id, destination_city_id, units, arrive_at, movement_type) with surviving attacker units, destination = b.attacker_city_id, arrive_at = NOW() + travel time. For travel time, look up island grid_x/grid_y for both cities and use the formula: max(1, ceil(sqrt(dx^2+dy^2) * 2)) minutes (matching baseMinutesPerGridUnit = 2).
   - If defender_won: UPDATE battles SET status = 'defender_won', updated_at = NOW(). Then update defender's city_units to match surviving snapshot: for each unit type in defender_units, upsert city_units SET quantity = snapshot_quantity.

**20260312000005_modify_process_arrivals.sql:**
