**supabase/functions/train-units/index.ts:**
Mirror upgrade-building structure. Key constants and logic:

1. Define CORS_HEADERS (same as upgrade-building)
2. Define UNIT_UNLOCK_LEVELS constant (from 04-RESEARCH.md) — sync comment pointing to unit_constants.dart
3. Define UNIT_BASE_COSTS constant (from 04-RESEARCH.md) — sync comment pointing to unit_constants.dart
4. Define UNIT_BASE_TIMES constant (from 04-RESEARCH.md) — sync comment pointing to unit_constants.dart
5. Deno.serve handler:
   - OPTIONS: return CORS
   - POST only
   - Parse body: { city_id, unit_type, quantity }
   - Validate quantity > 0 and quantity <= 50 (reasonable cap for v1)
   - Create anon client, get user (401 if not authenticated)
   - Create admin client (service role)
   - Verify city ownership: SELECT id FROM cities WHERE id = city_id AND owner_id = user.id (404 if not found)
   - Validate unit_type exists in UNIT_UNLOCK_LEVELS (400 if unknown)
   - Get required building: UNIT_UNLOCK_LEVELS[unit_type].building and .minLevel
   - Fetch building level: SELECT level FROM city_buildings WHERE city_id = city_id AND building_type = building (404 if building not found, 400 if level < minLevel with message "Requires {building} level {minLevel}")
   - Check training_queue vacancy: SELECT id FROM training_queue WHERE city_id = city_id (.maybeSingle()) — 409 "Training queue is busy" if row exists
   - Calculate total cost: UNIT_BASE_COSTS[unit_type] * quantity for each resource
   - Deduct resources: for each resource, call admin.rpc('deduct_resource', { p_city_id, p_resource_type, p_amount }) — return 400 "Insufficient {resource}" on error
   - Calculate finish_at: NOW() + UNIT_BASE_TIMES[unit_type] * quantity minutes
   - INSERT INTO training_queue: { city_id, unit_type, quantity, finish_at }
   - Catch unique_violation (error code 23505) and return 409 "Training queue is busy"
   - Return 200 { success: true, finish_at, unit_type, quantity }
