2. Run INFR-03 audit (RLS enabled on all public tables):
   ```bash
   docker exec supabase_db_ikariam psql -U postgres -d postgres -c "SELECT tablename, rowsecurity AS rls_enabled FROM pg_tables WHERE schemaname = 'public' ORDER BY tablename;"
   ```
   Expected: ALL rows show rls_enabled = true. Any false row is a BLOCKER.
   Also run the policy count check:
   ```bash
   docker exec supabase_db_ikariam psql -U postgres -d postgres -c "SELECT tablename, COUNT(*) AS policy_count FROM pg_policies WHERE schemaname = 'public' GROUP BY tablename ORDER BY tablename;"
   ```
   Expected: Every table has at least 1 policy.

3. Build Flutter web release:
   ```bash
   flutter build web --release
   ```
