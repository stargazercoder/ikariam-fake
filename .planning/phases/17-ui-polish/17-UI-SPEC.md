## Spacing Scale

Declared values (multiples of 4 only). Flutter uses `double` values, not CSS px.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4.0 | Icon gaps, tight inline padding (e.g. CircleAvatar radius gap) |
| sm | 8.0 | Compact list item spacing, internal widget padding |
| md | 16.0 | Default content padding, horizontal screen edge padding |
| lg | 24.0 | Section separation, card internal padding |
| xl | 32.0 | Major section breaks, AppBar height extension |
| 2xl | 48.0 | Large touch target minimum (e.g. icon-only buttons) |
| 3xl | 64.0 | Page-level top spacing when body extends behind AppBar |

Exceptions:
- City name label on grid: positioned with top offset `64.0` (3xl) to clear transparent AppBar action zone
- CircleAvatar unit icon: radius `16.0` (md), producing a 32px touch-friendly avatar
- City slot border: `2.0` width (intentionally sub-grid — not a spacing token, purely decorative stroke)

> Source: Established Flutter Material 3 conventions; CONTEXT.md AppBar/grid decisions

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14sp | 400 (regular) | 1.5 |
| Label | 12sp | 400 (regular) | 1.4 |
| Heading | 16sp | 600 (semibold) | 1.2 |
| Display | 20sp | 600 (semibold) | 1.2 |

Notes:
- City name label on grid: Display role (20sp, semibold) with `Shadow(blurRadius: 4, color: Colors.black54)` for readability over building grid background
- AppBar icon buttons (back, sign-out): retain system defaults from `AppBarTheme` (foreground white, icon 24sp)
- "Viewing enemy city — read only" banner: Label role (12sp, regular), white text on `Colors.red.shade800` background, full-width
- Unit type name in military list rows: Body role (14sp, regular)
- Unit count in military list rows: Heading role (16sp, semibold)

> Source: `app_theme.dart` Material 3 theme defaults; CONTEXT.md city name label decision

### Ownership Color Contract

| Ownership State | Color | Hex | Flutter Constant |
|----------------|-------|-----|-----------------|
| Own city | Green | `#43A047` | `Colors.green.shade600` |
| Enemy city | Red | `#E53935` | `Colors.red.shade600` |
| Empty slot | Grey | `#BDBDBD` | `Colors.grey.shade400` |

Ownership color usage:
- Island screen city slots: 2px border around slot container with `BorderRadius.circular(8)`
- World map island cells: 2px border around island cell container
- World map rule: own city present on island → green; no own city + enemy cities present → red; all empty → grey

## Component Contract

### CircleAvatar — Unit Type Icon

```
CircleAvatar(
  radius: 16.0,
  backgroundColor: unitTypeColors[unitType],
  child: Icon(unitTypeIcons[unitType], color: Colors.white, size: 16.0),
)
```

- Applied as `leading:` widget in `ListTile` for every unit row
- Screens: Barracks training queue, Shipyard training queue, Dispatch army lists, Battles screen battle reports
- Icon mapping lives in `lib/core/constants/unit_constants.dart` as `Map<UnitType, IconData> unitTypeIcons`
