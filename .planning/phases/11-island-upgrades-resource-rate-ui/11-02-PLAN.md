```dart
/// Wood cost to upgrade island resource level from [currentLevel] to currentLevel+1.
/// Formula: ceil(300 * 1.5^currentLevel). Mirrors donate-island-wood Edge Function.
int islandDonationCost(int currentLevel) {
  const baseCost = 300;
  const growth = 1.5;
  return (baseCost * pow(growth, currentLevel)).ceil();
}

/// Island production multiplier at a given resource level.
/// Level 0 = 1.0x, Level 5 = 1.5x, Level 10 = 2.0x.
double islandMultiplier(int resourceLevel) {
  return 1.0 + resourceLevel * 0.10;
}

/// Maximum island resource level.
const int maxIslandResourceLevel = 10;
```
Import `dart:math` for `pow`.

**3. Create production rate provider** (`lib/features/city/providers/production_rate_provider.dart`):
- Create a `Provider.autoDispose.family<Map<String, double>, String>` named `productionRateProvider` that takes cityId.
- Watch `buildingsStreamProvider(cityId)` to get buildings list. Extract as `List<CityBuilding>` or empty list on loading/error.
- Watch `cityEconomyStreamProvider(cityId)` to get happiness. Compute `productionMult = happiness < 0 ? 0.5 : 1.0`.
- Watch `cityProvider` to get island data. Extract `island['resource_level'] as int? ?? 0`. Compute `islandMult = 1.0 + islandLevel * 0.10`.
- For each production resource type (wood, marble, crystal, sulfur), find the matching building (sawmill, quarry, glassblower, sulfur_pit) from the buildings list. Use BuildingType enum to match.
- Compute hourly rate per resource: `workers * buildingLevel * 5.0 * productionMult * islandMult * 12` (12 ticks/hr at 5-min interval).
- Return `Map<String, double>` keyed by resource type name (e.g., 'wood', 'marble', etc.).
- Also create a `ProductionBreakdown` class in the same file:
```dart
class ProductionBreakdown {
  final double baseRate;      // workers * 1 * 5.0 * 12 (level-1 equivalent)
  final double buildingBonus; // additional from building level above 1
  final double islandBonus;   // contribution from island multiplier
  final double researchBonus; // always 0.0 in v1
  double get total => baseRate + buildingBonus + islandBonus + researchBonus;
}
```
- Create a `productionBreakdownProvider` that takes `(cityId, resourceTypeName)` as a record and returns a `ProductionBreakdown`. Use the same data sources. Compute:
  - `baseRate = workers * 1 * 5.0 * productionMult * 12` (what you'd get at building level 1)
  - `buildingBonus = workers * (buildingLevel - 1) * 5.0 * productionMult * 12` (additional from higher building levels)
  - `islandBonus = workers * buildingLevel * 5.0 * productionMult * (islandMult - 1.0) * 12` (additional from island level)
  - `researchBonus = 0.0`

Helper: Create a mapping function `BuildingType _productionBuilding(String resourceType)` that maps 'wood' -> BuildingType.sawmill, 'marble' -> BuildingType.quarry, 'crystal' -> BuildingType.glassblower, 'sulfur' -> BuildingType.sulfurPit.

Import building_constants for BuildingType, city_building model, buildings_provider, city_economy_provider, city_provider.
