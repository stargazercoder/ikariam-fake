  <action>
Create `supabase/functions/donate-island-wood/index.ts` following the exact pattern from `upgrade-building/index.ts`.

**Request body:** `{ city_id: string }`
- No `wood_amount` parameter needed — the cost is determined by the current island level.

**Wood cost per level (constant table):**
```typescript
const DONATION_COSTS: Record<number, number> = {
  0: 300, 1: 450, 2: 675, 3: 1013, 4: 1519,
  5: 2279, 6: 3418, 7: 5128, 8: 7691, 9: 11537,
};
// Formula: Math.ceil(300 * 1.5^currentLevel)
```

**Steps:**
1. CORS preflight handling (copy from upgrade-building)
2. Parse body: `{ city_id }` — validate city_id is a non-empty string
3. Auth: `anonClient.auth.getUser()` with Authorization header (copy pattern)
4. Admin client with service role key (copy pattern)
5. Verify caller owns the city: `admin.from('cities').select('id, island_id').eq('id', city_id).eq('owner_id', user.id).maybeSingle()` — reject 403 if not found
6. Read current island resource_level: `admin.from('islands').select('resource_level').eq('id', islandId).single()` — reject 400 if island not found
7. Reject if `resource_level >= 10` (already max level) — return 409
8. Compute wood cost from `DONATION_COSTS[currentLevel]`
9. Deduct wood: `admin.rpc('deduct_resource', { p_city_id: city_id, p_resource_type: 'wood', p_amount: woodCost })` — on error return 400 "Insufficient wood"
10. Atomic conditional UPDATE: `admin.from('islands').update({ resource_level: currentLevel + 1 }).eq('id', islandId).eq('resource_level', currentLevel).select('resource_level').single()` — if error (race condition, another player upgraded first), return 409 "Island already upgraded by another player"
11. Return success: `{ success: true, new_level: currentLevel + 1, wood_cost: woodCost }`

Use the same `errorResponse()` and `successResponse()` helper pattern from upgrade-building. Include CORS_HEADERS constant.
  </action>
