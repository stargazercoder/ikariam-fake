**Step 2: Create BattleLossChart widget**
Create `lib/features/battles/screens/widgets/battle_loss_chart.dart`:

A StatelessWidget that takes `List<BattleTurn> turns` and `bool isAttacker` as parameters.

Structure:
- Column with two sections: "Naval Losses" and "Land Losses"
- Each section has a header text, a `BarChart` widget, and a color legend
- If a phase has zero total casualties across all turns, show "No naval/land losses" text instead of empty chart

**Naval chart:**
- One bar group per turn (x-axis = turn number)
- Each bar has stacked segments for each naval unit type that had casualties
- Use `orderedNavalTypes` for consistent iteration order
- For attacker's losses: read `turn.navalAttackerCasualties`; for defender's: `turn.navalDefenderCasualties`
- Show BOTH attacker and defender losses side-by-side (two rods per bar group): left rod = attacker losses, right rod = defender losses
- Rod width: 14, spacing between rods: 4
- Use `BarChartRodStackItem(fromY, toY, color)` for stacking. Accumulate runningY per unit type.
- Filter out turns where the relevant casualties map is null (naval skipped)

**Land chart:**
- Same pattern as naval but uses `orderedLandTypes` and `landAttackerCasualties`/`landDefenderCasualties`
- Filter out turns where land casualties are null (land blocked)

**Chart configuration:**
- `BarChartData(alignment: BarChartAlignment.spaceAround, maxY: computed from max losses)`
- Bottom axis: turn numbers as "T1", "T2", etc.
- Left axis: hidden (clean look) or show integer values
- `swapAnimationDuration: Duration(milliseconds: 300)`
- No grid lines (clean look)
- Tooltip on touch showing unit type + count

**Legend widget:**
Build a Wrap widget with colored squares + unit type display names for all unit types that appear in any turn's casualties. Only show unit types that actually had losses (don't show all 13 if only 3 fought).
