**Part B — Edge Function:** Create a new Edge Function following the exact same pattern as upgrade-building/index.ts.

**Request:** POST `{ city_id: string, wine_spending_rate: number }`

**Validation steps:**
1. Handle CORS OPTIONS preflight (same CORS_HEADERS as upgrade-building)
2. Reject non-POST methods with 405
3. Parse JSON body, validate city_id is string, wine_spending_rate is number
4. Validate wine_spending_rate is integer between 0 and 100 (reject floats and out-of-range)
5. Authenticate caller via anon client (same pattern as upgrade-building)
6. Verify city ownership via admin client (same pattern as upgrade-building)
7. Update cities table: `admin.from('cities').update({ wine_spending_rate }).eq('id', city_id)`
8. Return successResponse with `{ success: true, wine_spending_rate }`

**Error responses:**
- 400: Invalid JSON, missing fields, invalid rate range
- 401: Not authenticated
- 403: City not found or not owned
- 500: Database error

Use the same helper functions (errorResponse, successResponse) as upgrade-building. Copy the CORS_HEADERS, auth pattern, and city ownership check directly.

Future<void> setWineRate({
  required String cityId,

    body: {
      'city_id': cityId,
      'wine_spending_rate': wineSpendingRate,
    },
  );
  if (response.status != 200) {
    throw Exception('Failed to set wine rate: ${response.data}');

}
