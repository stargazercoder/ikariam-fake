```dart
// Riverpod StreamProvider for real-time city economy data (population, happiness, wine_spending_rate).
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

/// StreamProvider that emits live economy data from the cities table.
/// Returns a Map with keys: 'population', 'happiness', 'wine_spending_rate'.
final cityEconomyStreamProvider = StreamProvider.autoDispose
    .family<Map<String, dynamic>?, String>((ref, cityId) {
  return Supabase.instance.client
      .from('cities')
      .stream(primaryKey: ['id'])
      .eq('id', cityId)
      .map((rows) => rows.isNotEmpty ? rows.first : null);
});
```

This mirrors the pattern from resourcesStreamProvider but watches the cities table instead of city_resources.

class _TavernWineSlider extends ConsumerStatefulWidget {
  final String cityId;
  final int tavernLevel;

  const _TavernWineSlider({
    required this.cityId,
    required this.tavernLevel,
  });

  @override
  ConsumerState<_TavernWineSlider> createState() => _TavernWineSliderState();
}
```

**State management:**
- `double _rate` — local slider value (0.0 to 1.0, maps to 0-100%)
- `Timer? _debounce` — 300ms debounce timer
- Initialize `_rate` from `cityEconomyStreamProvider` data (`wine_spending_rate / 100.0`)
- On slider change: update local state immediately, cancel previous timer, start new 300ms timer
- Timer callback: check `mounted`, then call `ref.read(cityRepositoryProvider).setWineRate(cityId: widget.cityId, wineSpendingRate: (_rate * 100).round())`
- In `dispose()`: cancel `_debounce`

**Display elements (from CONTEXT.md locked decisions):**
1. Slider label: "Wine Spending: {rate}%"
2. Happiness contribution: calculated locally as `(_rate * tavernLevel)` — show with emoji
3. Wine consumed per tick: `_rate * tavernLevel * 5.0` units/tick
4. Current wine stock: read from resourcesStreamProvider, find wine resource amount

**Layout in slider widget:**
```
Column(

    Text("Wine Spending"),
    Slider(value: _rate, min: 0, max: 1, divisions: 100, onChanged: _onSliderChanged),
