**Function 1: `bot_decide_upgrade(p_city_id uuid) RETURNS boolean`**

Signature: `LANGUAGE plpgsql SECURITY DEFINER SET search_path = ''`

Logic:
1. Check construction_queue vacancy: `SELECT id FROM public.construction_queue WHERE city_id = p_city_id LIMIT 1`. If FOUND, RETURN false.
2. Find cheapest upgradeable building: query `public.city_buildings WHERE city_id = p_city_id ORDER BY level ASC` and for each building compute cost using `CEIL(base_cost * POWER(1.5, current_level))` formula. Building base costs (hardcoded as a CTE or VALUES list):
   ```
   town_hall:    gold=100, wood=200
   warehouse:    wood=100, marble=50
   barracks:     wood=150, gold=100
   shipyard:     wood=200, marble=100, gold=150
   academy:      wood=100, crystal=100, gold=200
   embassy:      wood=80, marble=80, gold=100
   trading_port: wood=150, gold=120
   town_wall:    wood=200, marble=150
   hideout:      wood=100, gold=80
   tavern:       wood=120, gold=100
   sawmill:      wood=50, gold=50
   quarry:       wood=80, marble=30
   glassblower:  wood=80, crystal=30
   sulfur_pit:   wood=80, sulfur=30
   ```
3. For each building (ordered by level ASC), compute cost at current_level. Check if city_resources has enough of each resource type. If affordable, proceed to step 5. If no building is affordable, go to step 4.
4. Island donation fallback:
   - `SELECT i.id, i.resource_level FROM public.islands i JOIN public.cities c ON c.island_id = i.id WHERE c.id = p_city_id`
   - If resource_level >= 10, RETURN false (max level)
   - Donation cost = `CEIL(300.0 * POWER(1.5, resource_level))`
   - Check city wood >= donation cost. If insufficient, RETURN false
   - `PERFORM public.deduct_resource(p_city_id, 'wood', v_donation_cost)`
   - Conditional UPDATE: `UPDATE public.islands SET resource_level = resource_level + 1 WHERE id = v_island_id AND resource_level = v_expected_level`
   - Check ROW_COUNT. If 0 rows updated, accepted v1 edge case (wood already deducted). RETURN true either way.
5. If affordable building found:
   - Deduct each resource: `PERFORM public.deduct_resource(p_city_id, 'wood', v_wood_cost)` etc. for each non-zero resource type
   - Calculate finish_at: `NOW() + make_interval(mins => CEIL(1.0 * POWER(1.2, v_current_level))::int)`
   - INSERT: `INSERT INTO public.construction_queue (city_id, building_type, target_level, finish_at) VALUES (p_city_id, v_building_type, v_current_level + 1, v_finish_at)`
   - Wrap INSERT in BEGIN...EXCEPTION block catching `unique_violation (SQLSTATE 23505)` — if caught, another process beat us, RETURN false
   - RETURN true

**Function 2: `bot_decide_train(p_city_id uuid) RETURNS boolean`**

Signature: `LANGUAGE plpgsql SECURITY DEFINER SET search_path = ''`

Logic:
1. Check training_queue vacancy: `SELECT id FROM public.training_queue WHERE city_id = p_city_id LIMIT 1`. If FOUND, RETURN false.
2. Get barracks level: `SELECT level FROM public.city_buildings WHERE city_id = p_city_id AND building_type = 'barracks'`. If not found or level = 0, RETURN false.
3. Determine cheapest affordable land unit. Unit unlock levels:
   ```
   cook: barracks >= 1       hoplite: barracks >= 1
   phalanx: barracks >= 2    archer: barracks >= 2
   cavalry: barracks >= 3    medic: barracks >= 3
   catapult: barracks >= 4   mortar: barracks >= 5
   ```
   Unit costs per unit:
   ```
   cook:     wood=20, gold=20         (total=40)
   hoplite:  wood=40, gold=30         (total=70)
   phalanx:  wood=60, marble=20, gold=50   (total=130)
   archer:   wood=50, crystal=20, gold=40  (total=110)
   medic:    wood=30, crystal=30, gold=60  (total=120)
   cavalry:  wood=80, gold=100        (total=180)
   catapult: wood=120, sulfur=30, gold=80  (total=230)
   mortar:   wood=100, sulfur=50, gold=120 (total=270)
   ```
   Use a CTE/VALUES list sorted by total cost ASC. For each unit type (cheapest first), check barracks level meets unlock requirement AND city_resources can afford at least 1 unit. Pick the first affordable unit.
4. No affordable land unit found: RETURN false
5. Calculate quantity: for the chosen unit type, find the limiting resource. `quantity = LEAST(50, FLOOR(min_resource_available / per_unit_cost_for_that_resource))` across all resource types required. Minimum quantity = 1.
6. Deduct resources: `PERFORM public.deduct_resource(p_city_id, resource_type, cost * quantity)` for each resource type.
7. Calculate finish_at: base_time = 1 minute per unit. Dev speed multiplier = 0.2.
   `duration_minutes = GREATEST(1, CEIL(1.0 * quantity * 0.2))` -- hardcode 0.2 dev speed, add comment: `-- TODO: parameterize via game_config table when production deployment is planned`
   `v_finish_at = NOW() + make_interval(mins => duration_minutes)`
8. INSERT: `INSERT INTO public.training_queue (city_id, unit_type, quantity, finish_at) VALUES (p_city_id, v_unit_type, v_quantity, v_finish_at)`
   Wrap in BEGIN...EXCEPTION catching unique_violation (SQLSTATE 23505). If caught, RETURN false.
9. RETURN true
