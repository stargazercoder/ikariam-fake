**20260311000011_create_city_units.sql:**
- CREATE TABLE public.city_units: id (uuid PK DEFAULT gen_random_uuid()), city_id (uuid NOT NULL FK cities ON DELETE CASCADE), unit_type (text NOT NULL), quantity (integer NOT NULL DEFAULT 0 CHECK >= 0), updated_at (timestamptz NOT NULL DEFAULT NOW())

**20260311000012_create_training_queue.sql:**
- CREATE TABLE public.training_queue: id (uuid PK), city_id (uuid NOT NULL FK cities ON DELETE CASCADE), unit_type (text NOT NULL), quantity (integer NOT NULL CHECK > 0), finish_at (timestamptz NOT NULL), created_at (timestamptz NOT NULL DEFAULT NOW())
- UNIQUE(city_id) — one active training at a time (v1 simplicity)
- Same 13-value CHECK constraint on unit_type
- ENABLE ROW LEVEL SECURITY
- REPLICA IDENTITY FULL
- RLS policy: training_queue_select_owner — same pattern as city_units
- ALTER PUBLICATION supabase_realtime ADD TABLE public.training_queue

**20260311000013_create_unit_movements.sql:**
- CREATE TABLE public.unit_movements: id (uuid PK), origin_city_id (uuid NOT NULL FK cities), destination_city_id (uuid NOT NULL FK cities), owner_id (uuid NOT NULL FK auth.users), units (jsonb NOT NULL), depart_at (timestamptz NOT NULL DEFAULT NOW()), arrive_at (timestamptz NOT NULL), created_at (timestamptz NOT NULL DEFAULT NOW())

- ALTER PUBLICATION supabase_realtime ADD TABLE public.unit_movements

**20260311000014_training_functions.sql:**
Two functions, both SECURITY DEFINER SET search_path = '':

1. `complete_training()` RETURNS void — mirrors complete_building_upgrades():
   - FOR loop over training_queue WHERE finish_at <= NOW()
   - For each: INSERT INTO city_units (city_id, unit_type, quantity, updated_at) VALUES (...) ON CONFLICT (city_id, unit_type) DO UPDATE SET quantity = city_units.quantity + EXCLUDED.quantity, updated_at = NOW()
   - DELETE FROM training_queue WHERE id = q.id

2. `deduct_units(p_city_id uuid, p_unit_type text, p_quantity integer)` RETURNS void — mirrors deduct_resource():
   - UPDATE city_units SET quantity = quantity - p_quantity, updated_at = NOW() WHERE city_id = p_city_id AND unit_type = p_unit_type AND quantity >= p_quantity
   - GET DIAGNOSTICS v_rows = ROW_COUNT
   - IF v_rows = 0 THEN RAISE EXCEPTION 'Insufficient %', p_unit_type USING ERRCODE = 'insufficient_resources'
