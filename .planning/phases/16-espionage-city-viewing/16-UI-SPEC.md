## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gaps within rows (e.g., `SizedBox(width: 4)`) |
| sm | 8px | Between dialog sections, between card rows (`SizedBox(height: 8)`) |
| md | 16px | Dialog padding, list padding, default content spacing |
| lg | 24px | Divider height in dialogs (`Divider(height: 24)`) |
| xl | 32px | Empty state vertical padding (`EdgeInsets.all(32)`) |
| 2xl | 48px | Minimum tappable button height (`minimumSize: Size(double.infinity, 48)`) |
| 3xl | 64px | Empty state icon size |

**Source:** Extracted from `trade_dialog.dart`, `battles_screen.dart`, `movements_screen.dart` — consistent 4/8/16/24 grid used throughout.

Exceptions:
- Touch targets for action buttons in city action dialog: minimum 48px height (matches `elevatedButtonTheme` in AppTheme).
- Spy report dialog max width: 480px, max height: 640px (matches trade dialog `BoxConstraints(maxWidth: 480, maxHeight: 640)`).
- Building cell tap area: inherits `BuildingCell` sizing from `city_grid_screen.dart` — no change for read-only mode.

## Typography

Flutter Material 3 TextTheme is the source of truth. Declared roles mapped to M3 tokens:

| Role | M3 Token | Approx Size | Weight | Line Height |
|------|----------|-------------|--------|-------------|
| Body | `bodyMedium` | 14sp | 400 (regular) | 1.5 |
| Label | `labelLarge` | 14sp | 700 (bold) | 1.3 |
| Heading | `titleMedium` | 16sp | 700 (bold) | 1.4 |
| Display | `titleLarge` | 22sp | 700 (bold) | 1.2 |

**Allowed font weights:** 400 (regular) and 700 (bold) only — exactly 2 weights.

Specific typography decisions for Phase 16:

- **Spy report dialog title** (city name): `titleLarge` + `fontWeight: FontWeight.bold` — same as trade dialog header. Source: `trade_dialog.dart` line 134.
- **Spy report section headers** (Resources, Buildings, Army): `labelLarge` + `color: colorScheme.primary` + `fontWeight: FontWeight.bold` — same as `_SectionHeader` in battles screen. Source: `battles_screen.dart` line 125.
- **Spy report data rows**: `bodyMedium` at weight 400 for labels, `bodySmall` at weight 700 for values.
- **Spy log list tile title**: `bodyMedium` + `fontWeight: FontWeight.bold` — matches `_BattleTile` pattern. Source: `battles_screen.dart` line 171.
- **Enemy city view AppBar title**: `titleLarge` in AppBar foreground (white) — same as all AppBars.
- **Read-only notice chip**: `bodySmall` at weight 400, color `colorScheme.onSurface.withAlpha(140)`.

## Color

**Source:** `lib/core/theme/app_theme.dart`

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FAFAF7` (off-white `_surfaceColor`) | Scaffold background, dialog background, card surfaces |
| Secondary (30%) | `#FFFFFF` (white) | Card fill (`cardTheme.color`), input fill, dialog `Material` surface |
| Accent (10%) | `#1A237E` (deep navy `primaryColor`) | See reserved-for list below |
| Destructive | `#B71C1C` (`_errorColor`) | Destructive actions only (see below) |

**Accent (`#1A237E`) reserved for:**
1. Spy action button ("Spy (100 gold)") — `FilledButton` uses primaryColor background.
2. Section header labels in spy report dialog and spy log.
3. Resource/building icons in spy report dialog.
4. Active construction ETA label in enemy city view (countdown timer).
5. "View City" enabled state button.

**Secondary accent (`#FFD700` gold) reserved for:**
- Gold cost inline label in city action dialog: "Spy (100 gold)" — highlight the cost figure in `secondaryColor` to signal resource expenditure. Consistent with how gold is displayed in resource bars.

**Destructive (`#B71C1C`) reserved for:**
- Enemy city view AppBar (`Colors.red.shade800` ≈ `#C62828`) — locked decision from CONTEXT.md. This is the one location where a red AppBar signals "enemy territory."
- Insufficient gold error SnackBar background (`colorScheme.error`).

**Disabled / greyed-out:**
- "View City (spy first)" button when no spy report exists: `onPressed: null` — Flutter auto-applies disabled style (foreground `onSurface.withAlpha(97)`, no fill). Do not manually override disabled color.

## Interaction Contract

### City Action Dialog — New Buttons

The `_showCityActionDialog` on `island_screen.dart` gains two new entries for enemy cities, placed after "Trade":

| Button | Style | Enabled Condition | Tap Action |
|--------|-------|-------------------|------------|
| "Spy (100 gold)" | `FilledButton` (primary) | Always enabled for enemy cities | Close dialog → call `showSpyReportDialog()` |
| "View City" | `OutlinedButton` | `hasSpiedProvider` returns true | Close dialog → push `/city-view` |
| "View City (spy first)" | `OutlinedButton` | `onPressed: null` (disabled) | None — no action, teaches the mechanic |

Button order for enemy city (top to bottom in dialog actions):
1. Attack — `OutlinedButton` with error color (existing)
2. Trade — `FilledButton` (existing)
3. Spy (100 gold) — `FilledButton`
4. View City / View City (spy first) — `OutlinedButton`

### Spy Report Dialog

Triggered immediately when "Spy (100 gold)" is tapped. No confirmation step (locked decision).

| State | Visual |
|-------|--------|
| Loading | `CircularProgressIndicator` centered in dialog body; close button disabled |
| Success | Report sections rendered (see layout below); "View City" and "Close Report" buttons visible |
| Insufficient gold | Dialog pops; SnackBar shown with error color and message |
| Network error | Dialog pops; SnackBar shown with error color and retry message |

**Spy Report Dialog Layout (success state, top to bottom):**
1. Header row: `Icons.visibility` (32px, primaryColor) + city name (`titleLarge` bold) + close `IconButton(icon: Icon(Icons.close), tooltip: 'Close spy report', onPressed: ...)`
2. `Divider(height: 24)`
3. Subtitle row: owner name (`bodyMedium`, `Colors.grey.shade600`)
4. `Divider(height: 24)`
5. Section: "Resources" header + 5 resource rows (icon + name + amount)
6. `Divider(height: 16)`
7. Section: "Buildings" header + building rows (icon + building name + "Lv N")
8. `Divider(height: 16)`
9. Section: "Army" header + single row "Total units: N" (`bodyMedium`)
10. `SizedBox(height: 8)`
11. "View City" button — `FilledButton` full width (height 48)
12. `SizedBox(height: 8)`
13. "Close Report" button — `OutlinedButton` full width

**Spy icon:** `Icons.visibility` — represents scouting/observation without implying violence.

### Enemy City View Screen

| Element | Specification |
|---------|---------------|
| AppBar background | `Colors.red.shade800` (#C62828) — locked decision |
| AppBar title | "CityName (PlayerName)" — `titleLarge`, white foreground |
| AppBar actions | None — no action buttons, read-only |
| Body | `BuildingsGrid` with `readOnly: true` + `currentResources: const []` |
| Construction banner | Rendered as-is (shows ETA countdown) — adds strategic intel value |
| Resources panel | Not shown — resources visible only in spy report (locked decision) |
| Read-only notice | Banner below AppBar: `Container` with `Colors.red.shade50` background, `Icon(Icons.visibility_outlined)` + text "Viewing enemy city — read only" in `bodySmall` |

### Spy Log Screen

Accessible from the Battles screen via a `FloatingActionButton` with `Icons.history` label "Spy Log", or as a bottom sheet. Exact placement: planner decides between new route (`/spy-log`) or `showModalBottomSheet` from BattlesScreen.

| State | Visual |
|-------|--------|
| Loading | `CircularProgressIndicator` centered |
| Empty | Icon `Icons.visibility_off` (64px, grey) + "No spy reports yet" (`titleMedium`, muted) + "Tap 'Spy' on an enemy city to gather intelligence." (`bodySmall`, grey) |
| Data | `ListView` of `_SpyLogTile` cards |

**Spy Log Tile layout (matches `_BattleTile` pattern):**
- Leading: `Icons.visibility` icon, `primaryColor`
- Title: city name (`bodyMedium`, `fontWeight: FontWeight.bold`)
- Subtitle: report timestamp formatted as "Mar 16, 2026 · 14:32" (`bodySmall`, grey)
- Trailing: `Icons.chevron_right` (grey) — taps open spy report dialog (read mode, no gold cost re-run)

**Sort order:** Most recent first (`created_at DESC`).
