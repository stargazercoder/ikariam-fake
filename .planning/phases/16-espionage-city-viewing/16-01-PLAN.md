Create the spy_reports table with the following exact SQL:

```sql
-- Spy reports table — stores espionage results for each player
CREATE TABLE public.spy_reports (
  id             uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  player_id      uuid NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  target_city_id uuid NOT NULL REFERENCES public.cities(id) ON DELETE CASCADE,
  report_data    jsonb NOT NULL,
  created_at     timestamptz NOT NULL DEFAULT now()
);

-- Index for spy log queries (player's own reports, most recent first)
CREATE INDEX spy_reports_player_id_created_at_idx
  ON public.spy_reports (player_id, created_at DESC);

-- RLS: players can only read their own reports
ALTER TABLE public.spy_reports ENABLE ROW LEVEL SECURITY;

CREATE POLICY "players read own spy reports"
  ON public.spy_reports FOR SELECT
  USING (player_id = auth.uid());
-- Edge Function inserts with service_role (bypasses RLS)
```

**Edge Function `spy-city/index.ts`:**

Follow the `send-trade/index.ts` pattern exactly. The function:

1. Handle CORS preflight (OPTIONS → 204 with CORS_HEADERS). Use identical CORS_HEADERS constant as send-trade.
2. Parse body: `{ target_city_id: string }` — validate it is a non-empty string.
3. Auth: create anonClient with Authorization header, call `anonClient.auth.getUser()`, return 401 if no user.
4. Create admin client with service_role key (bypasses RLS).
5. Find caller's city: `SELECT id FROM cities WHERE owner_id = user.id LIMIT 1` — return 404 if no city.
6. Guard: verify `target_city.owner_id != user.id` — return 400 with "You cannot spy on your own city" if equal.
7. Check gold balance: `SELECT amount FROM city_resources WHERE city_id = playerCityId AND resource_type = 'gold'` — return 400 "Not enough gold. You need 100 gold to spy." if amount < 100.
8. Verify target city exists: `SELECT id, name, owner_id FROM cities WHERE id = target_city_id` — return 404 if not found.
9. Get target owner display_name: `SELECT display_name FROM profiles WHERE id = targetCity.owner_id` using admin client.
10. Deduct 100 gold atomically: `admin.rpc('deduct_resources', { p_city_id: playerCityId, p_resource_type: 'gold', p_amount: 100 })` — return 400 on error.
11. Query target city data:
    - Resources: `SELECT resource_type, amount FROM city_resources WHERE city_id = target_city_id` → build `resources` object `{ wood: N, marble: N, crystal: N, sulfur: N, gold: N }`.
    - Buildings: `SELECT building_type, level FROM city_buildings WHERE city_id = target_city_id` → build `buildings` object `{ town_hall: N, warehouse: N, ... }`.
    - Army count: `SELECT COALESCE(SUM(quantity), 0) as total FROM city_units WHERE city_id = target_city_id` → single integer `army_count`.
12. Build report_data JSONB:
    ```json
    {
      "city_name": targetCity.name,
      "owner_name": ownerProfile.display_name,
      "resources": { "wood": 500, "marble": 200, ... },
      "buildings": { "town_hall": 3, "warehouse": 2, ... },
      "army_count": 42
    }
    ```
13. Insert spy_report: `admin.from('spy_reports').insert({ player_id: user.id, target_city_id, report_data }).select().single()`.
14. Return: `successResponse({ report: { id, target_city_id, report_data, created_at } })`.

Use `import { createClient } from 'jsr:@supabase/supabase-js@2';` at the top.
Define `CORS_HEADERS`, `errorResponse()`, `successResponse()` identical to send-trade pattern.

**SpyReport model `lib/features/espionage/models/spy_report.dart`:**

```dart
class SpyReport {
  const SpyReport({
    required this.id,
    required this.targetCityId,
    required this.targetCityName,
    required this.ownerName,
    required this.createdAt,
    required this.resources,
    required this.buildings,
    required this.armyCount,
  });

  final String id;
  final String targetCityId;
  final String targetCityName;
  final String ownerName;
  final DateTime createdAt;
  final Map<String, int> resources;   // resource_type -> amount (all 5 types)
  final Map<String, int> buildings;   // building_type -> level
  final int armyCount;                // total units, no per-type breakdown

  factory SpyReport.fromJson(Map<String, dynamic> json) {
    final data = json['report_data'] as Map<String, dynamic>;
    return SpyReport(
      id: json['id'] as String,
      targetCityId: json['target_city_id'] as String,
      targetCityName: data['city_name'] as String? ?? '',
      ownerName: data['owner_name'] as String? ?? 'Unknown',
      createdAt: DateTime.parse(json['created_at'] as String),
      resources: (data['resources'] as Map<String, dynamic>)
          .map((k, v) => MapEntry(k, (v as num).toInt())),
      buildings: (data['buildings'] as Map<String, dynamic>)
          .map((k, v) => MapEntry(k, (v as num).toInt())),
      armyCount: (data['army_count'] as num).toInt(),
    );
  }
}
```

CRITICAL: Use `(v as num).toInt()` for ALL numeric JSONB fields — not `v as int` (JSONB cast inconsistency from STATE.md tech debt).

**Providers `lib/features/espionage/providers/espionage_providers.dart`:**

```dart
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:supabase_flutter/supabase_flutter.dart';
import '../data/espionage_repository.dart';
import '../models/spy_report.dart';

final espionageRepositoryProvider = Provider<EspionageRepository>((ref) {
  return const EspionageRepository();
});

/// Fetches all spy reports for the current player, ordered by created_at DESC.
final spyReportsProvider = FutureProvider.autoDispose<List<SpyReport>>((ref) async {
  final repo = ref.read(espionageRepositoryProvider);
  return repo.fetchSpyReports();
});

/// Returns true if the current player has at least one spy report for the given city.
final hasSpiedProvider = FutureProvider.autoDispose.family<bool, String>((ref, targetCityId) async {
  final userId = Supabase.instance.client.auth.currentUser?.id;
  if (userId == null) return false;
  final row = await Supabase.instance.client
      .from('spy_reports')
      .select('id')
      .eq('player_id', userId)
      .eq('target_city_id', targetCityId)
      .limit(1)
      .maybeSingle();
  return row != null;
});
```
