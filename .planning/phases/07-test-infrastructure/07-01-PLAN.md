Functions to create:

1. `dev_inject_resources(p_city_id uuid, p_wood int DEFAULT 5000, p_marble int DEFAULT 5000, p_crystal int DEFAULT 5000, p_sulfur int DEFAULT 5000, p_gold int DEFAULT 5000) RETURNS void`:
   - UPDATE city_resources SET amount = LEAST(amount + p_{type}, 99999) for each resource type
   - Use 5 sequential UPDATE statements matching on city_id AND resource_type

2. `dev_level_up_building(p_city_id uuid, p_building_type text, p_target_level int DEFAULT 0) RETURNS void`:
   - If p_target_level = 0, increment current level by 1
   - Otherwise set level = p_target_level
   - UPDATE city_buildings SET level = ... WHERE city_id = p_city_id AND building_type = p_building_type

3. `dev_spawn_units(p_city_id uuid, p_unit_type text, p_quantity int DEFAULT 50) RETURNS void`:
   - INSERT INTO city_units (city_id, unit_type, quantity) VALUES (p_city_id, p_unit_type, p_quantity) ON CONFLICT (city_id, unit_type) DO UPDATE SET quantity = city_units.quantity + EXCLUDED.quantity
   - ON CONFLICT handles case where unit type already exists for city

4. `dev_trigger_battle(p_attacker_city_id uuid, p_defender_city_id uuid) RETURNS uuid`:
   - Get attacker and defender owner_ids from cities table
   - INSERT INTO battles (attacker_id, defender_id, attacker_city_id, defender_city_id, status, turn_number, next_turn_at) with status='active', turn_number=0, next_turn_at=NOW()+INTERVAL '30 seconds'
   - RETURN the new battle ID

All functions: LANGUAGE plpgsql, SECURITY DEFINER SET search_path = ''.
