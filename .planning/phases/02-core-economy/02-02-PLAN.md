  <action>
    Create the Edge Function at `supabase/functions/upgrade-building/index.ts`. This is the ONLY client-facing mutation for building upgrades.

    The Edge Function must:

    1. Parse request body: `{ city_id: string, building_type: string }`
    2. Validate building_type is one of the 10 valid types
    3. Authenticate the caller via anon key client: `supabase.auth.getUser()` using the Authorization header
    4. Verify caller owns the city: SELECT from cities WHERE id = city_id AND owner_id = user.id
    5. Create a service role admin client for mutations (bypasses RLS per project decision INFR-02)
    6. Check no active construction: SELECT from construction_queue WHERE city_id AND finish_at > NOW(). If found, return 409 `{ error: 'Construction queue is busy' }`
    7. Get current building level from city_buildings (default to 0 if no row)
    8. Calculate upgrade cost: base_cost * 1.5^current_level for each resource (ceil'd). Use the SAME base cost values as building_constants.dart — define them as constants in the Edge Function file.
    9. For each resource cost, call `admin.rpc('deduct_resource', { p_city_id, p_resource_type, p_amount })`. If any fails, return 400 `{ error: 'Insufficient {resource}' }`. NOTE: This is not atomic across resources — if wood deduction succeeds but marble fails, wood is lost. For v1 this is acceptable. A future improvement would wrap in a single SQL transaction.
    10. Calculate finish_at: `NOW() + ceil(base_time * 1.2^current_level) minutes`. Use the SAME base time values as building_constants.dart.
    11. INSERT into construction_queue: { city_id, building_type, target_level: current_level + 1, finish_at }
    12. Return 200 `{ success: true, finish_at, duration_minutes, target_level }`

    Use `Deno.serve(async (req) => { ... })` pattern.
    Import: `import { createClient } from 'jsr:@supabase/supabase-js@2'`

    Define BASE_COSTS and BASE_TIMES as Record<string, ...> constants at the top of the file, matching the Dart building_constants.dart values exactly.

    Handle CORS: Add `Access-Control-Allow-Origin: *` and handle OPTIONS preflight.

    Error responses must always be JSON with `{ error: string }`.
