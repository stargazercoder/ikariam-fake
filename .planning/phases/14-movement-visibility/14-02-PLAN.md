**2. _MovementCard (ConsumerWidget, private)**

Takes `final UnitMovement movement` in constructor.

Layout per UI-SPEC.md `_MovementCard layout` section:

```dart
Card(
  margin: const EdgeInsets.symmetric(vertical: 4),
  child: Padding(
    padding: const EdgeInsets.all(12),
    child: Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        // Row 1: Movement type icon + destination city name
        Row(
          children: [
            Icon(
              movement.movementType == 'return'
                  ? Icons.call_received
                  : Icons.call_made,
              size: 18,
              color: movement.movementType == 'return'
                  ? Colors.grey.shade600
                  : Theme.of(context).colorScheme.primary,
            ),
            const SizedBox(width: 8),
            Expanded(
              child: Consumer(
                builder: (context, ref, _) {
                  final cityNameAsync = ref.watch(
                    cityNameProvider(movement.destinationCityId),
                  );
                  return Text(
                    cityNameAsync.when(
                      data: (name) => name ?? movement.destinationCityId,
                      loading: () => '...',
                      error: (_, __) => movement.destinationCityId,
                    ),
                    style: theme.textTheme.titleSmall?.copyWith(
                      fontWeight: FontWeight.bold,
                    ),
                  );
                },
              ),
            ),
          ],
        ),
        // Row 2: Unit summary
        const SizedBox(height: 4),
        Text(
          movement.units.entries
              .map((e) => '${unitTypeFromDbName(e.key).displayName} x${e.value}')
              .join(', '),
          style: theme.textTheme.bodySmall?.copyWith(
            color: Colors.grey.shade600,
          ),
        ),
        // Row 3: Cargo (conditional — only if cargo exists and non-empty)
        if (movement.cargo != null && movement.cargo!.isNotEmpty) ...[
          const SizedBox(height: 4),
          Wrap(
            spacing: 8,
            children: movement.cargo!.entries.map((e) {
              return Text(
                '${e.key}: ${e.value}',
                style: theme.textTheme.bodySmall?.copyWith(
                  color: Colors.grey.shade600,
                ),
              );
            }).toList(),
          ),
        ],
        // Row 4: ETA countdown
        const SizedBox(height: 8),
        Row(
          children: [
            Icon(Icons.timer, size: 14, color: Colors.grey.shade600),
            const SizedBox(width: 4),
            Text(
              'Arriving in: ',
              style: theme.textTheme.bodySmall,
            ),
            CountdownTimerWidget(
              finishAt: movement.arriveAt,
              style: theme.textTheme.bodySmall?.copyWith(
                fontWeight: FontWeight.bold,
                fontFeatures: [const FontFeature.tabularFigures()],
              ),
            ),
          ],
        ),
      ],
    ),
  ),
)
```

IMPORTANT implementation notes:
- Use `ref.watch(allMovementsStreamProvider)` (the stream provider, not the plain provider) for `.when()` pattern to get loading/error/data states
- City name resolution uses `cityNameProvider(movement.destinationCityId)` per-card with Consumer widget
- Unit display names use `unitTypeFromDbName(e.key).displayName` from unit_constants.dart — do NOT hand-roll string mapping
- CountdownTimerWidget reuse from `lib/features/city/widgets/countdown_timer_widget.dart` — do NOT build custom timer
- `import 'dart:ui';` needed for `FontFeature.tabularFigures()`
- Cards are read-only, no tap handlers
- No "arrived" transition state — Realtime DELETE removes the row and the card disappears naturally
