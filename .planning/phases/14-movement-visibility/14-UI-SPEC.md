## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gaps, inline separators (e.g. timer icon + label) |
| sm | 8px | Card internal row spacing, unit summary gap below title row |
| md | 16px | Card internal padding (all sides), screen body padding |
| lg | 24px | Vertical gap between sections (e.g. screen title to list) |
| xl | 32px | Not used in this phase |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- Movement card vertical margin: 4px (`margin: EdgeInsets.symmetric(vertical: 4)`) — matches existing `_MovementCard` pattern in `dispatch_screen.dart`. Source: RESEARCH.md + codebase.
- Card internal padding: 12px is used in existing `_MovementCard` (not a multiple of 4). The new MovementsScreen card adopts 12px for the card content padding to remain visually consistent with existing cards. Declared as project exception.

## Typography

Flutter `TextTheme` roles mapped from Material 3 defaults (no custom sizes declared in AppTheme):

| Role | Flutter TextTheme Role | Approx Size | Weight | Line Height |
|------|----------------------|-------------|--------|-------------|
| Screen title | `titleLarge` | 22sp | w600 semibold | 1.2 |
| Card title / destination name | `titleSmall` | 14sp | w700 bold | 1.2 |
| Unit summary / secondary info | `bodySmall` | 12sp | w400 regular | 1.5 |
| ETA countdown | `bodySmall` + `FontFeature.tabularFigures` | 12sp | w700 bold | 1.5 |

Rules:
- Exactly 2 weights used: regular (w400) and bold/semibold (w600–w700).
- `titleSmall` with `fontWeight: FontWeight.bold` for card heading row — matches existing `_MovementCard` pattern.
- `bodySmall` with `color: Colors.grey.shade600` for secondary text (unit summary, helper labels) — matches existing pattern.
- `bodySmall` + `FontFeature.tabularFigures` + `fontWeight: FontWeight.bold` for countdown timer — matches existing `CountdownTimerWidget` usage in `dispatch_screen.dart`.

Source: direct codebase inspection of `dispatch_screen.dart` and `countdown_timer_widget.dart`.

## Color

Tokens pulled from `lib/core/theme/app_theme.dart`:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FAFAF7` (off-white surface) | `Scaffold` background, screen background |
| Secondary (30%) | `Colors.white` card fill | `Card` widget background (elevation 2, radius 12) |
| Accent (10%) | `#1A237E` (deep navy primary) | Movement type icon color, section label color via `colorScheme.primary` |
| Destructive | `#B71C1C` (error red) | Not used in this phase — no destructive actions |

Accent reserved for:
1. Section label text (`Theme.of(context).colorScheme.primary`) — e.g. "Active Movements" heading
2. Movement type icon tint for attack movements (sword icon in navy primary)
3. Bottom nav tab icon when selected (Material `NavigationBar` uses `colorScheme.primary` automatically)

Return movement icon (`Icons.arrow_u_turn_left` or `Icons.undo`): use `Colors.grey.shade600` to distinguish from attack (no accent on return).

Cargo resource amounts: plain `Colors.grey.shade800` on white card surface — no accent color for cargo values.

Source: `app_theme.dart` — direct inspection.

## Screen Layout

### MovementsScreen

```
Scaffold
  AppBar: title = "Movements"
  body: Consumer
    AsyncValue.when(
      loading: Center > CircularProgressIndicator
      error:   Center > Text(error copy)
      data:    movements.isEmpty
                 ? Center > Column(icon + heading + body)
                 : ListView.builder(
                     padding: EdgeInsets.all(16),   // md
                     itemBuilder: _MovementCard
                   )
    )
```

### _MovementCard layout

```
Card (margin: vertical 4px, padding: 12px all sides)
  Column(crossAxisAlignment: start)
    Row
      Icon(movement type, size 18, color: primary if attack / grey600 if return)
      SizedBox(width: 8)               // sm
      Expanded > Text(destinationCityName, titleSmall, bold)
    SizedBox(height: 4)                // xs
    Text(unitSummary, bodySmall, grey600)
    if cargo != null && cargo.isNotEmpty:
      SizedBox(height: 4)              // xs
      Wrap(spacing: 8) > [Text('ResourceName: amount', bodySmall, grey600), ...]
    SizedBox(height: 8)                // sm
    Row
      Icon(Icons.timer, size: 14, color: grey600)
      SizedBox(width: 4)               // xs
      Text('Arriving in: ', bodySmall)
      CountdownTimerWidget(finishAt, bodySmall + bold + tabularFigures)
```

## Interaction Contract

| State | Trigger | Visual Response |
|-------|---------|----------------|
| Loading | Stream initializing | `Center > CircularProgressIndicator()` — default Material 3 size/color |
| Empty | Stream data = empty list | Empty state UI (see Copywriting section) |
| Populated | Stream data = N movements | `ListView.builder` with N `_MovementCard` items, sorted by ETA soonest first |
| New movement | Realtime INSERT arrives | Card appears at correct ETA-sorted position — no animation required, list rebuilds naturally |
| Movement arrives | Realtime DELETE arrives | Card disappears immediately — no "arrived" flash state, no SnackBar |
| Error | Stream emits error | `Center > Text(error copy, bodyMedium, error color)` |
| City name loading | `cityNameProvider` pending | Show `'...'` as destination text while FutureProvider resolves |
| City name loaded | `cityNameProvider` resolved | Destination text updates to full city name |

No tap interactions on movement cards — cards are read-only display. No swipe-to-dismiss, no delete, no detail drill-down in Phase 14.
